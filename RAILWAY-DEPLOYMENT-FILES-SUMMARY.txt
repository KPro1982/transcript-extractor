================================================================================
  🆘 COMMON ISSUES & SOLUTIONS
================================================================================

ISSUE: Backend won't start
SOLUTION: 
  - Check logs in Railway dashboard
  - Verify OPENAI_API_KEY is set and valid
  - Ensure DATABASE_URL and REDIS_URL are present (automatic)
  - Check for port conflicts (should use 8000)

ISSUE: Frontend can't connect to backend
SOLUTION:
  - Verify NEXT_PUBLIC_API_URL uses https:// (not http://)
  - Check FRONTEND_URL is set in backend environment
  - Look for CORS errors in browser DevTools console
  - Ensure backend is running and accessible

ISSUE: Worker not processing jobs
SOLUTION:
  - Verify custom start command is set correctly
  - Check Redis connection in worker logs
  - Ensure worker has all backend environment variables
  - Look for Celery connection errors in logs

ISSUE: Validation script fails
SOLUTION:
  - Wait 2-3 minutes for services to fully start
  - Check individual service health in Railway dashboard
  - Review specific error messages from validation
  - Verify URLs are correct (https:// for HTTP, wss:// for WebSocket)

ISSUE: Out of memory errors
SOLUTION:
  - Increase service memory in Railway settings
  - Consider scaling worker replicas
  - Check for memory leaks in logs
  - Optimize resource allocation

ISSUE: High costs
SOLUTION:
  - Review resource usage in Railway dashboard
  - Scale down unnecessary resources
  - Ensure caching is working (check Redis logs)
  - Monitor API usage and optimize requests

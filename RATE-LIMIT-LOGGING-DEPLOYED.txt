Enhanced logging to diagnose stuck processing on large documents:

1. **OpenAI Provider Logging** (openai_provider.py)
   • Logs retry-after time from 429 responses
   • Logs remaining requests/tokens from rate limit headers
   • Shows full HTTP headers on rate limit
   • Visual indicators: ⚠️ for rate limits, ❌ for errors, ⏱️ for timeouts
   • Separate messages for single, batch, classify, and combined calls

2. **AI Service Logging** (ai_service.py)
   • Logs which batch hit rate limit
   • Shows completed count vs total
   • Tracks fallback provider usage
   • Shows total items in document context

3. Look for these patterns:

   PATTERN 1: Rate Limited (Expected for 1000+ items)
   → See "⚠️  RATE LIMIT" messages
   → Will show retry-after time
   → Should continue after waiting

   PATTERN 2: Timeout
   → See "⏱️  TIMEOUT" messages
   → Individual request took too long
   → May need to increase timeout

   PATTERN 3: API Error
   → See "❌ OpenAI API error" messages
   → Check error details
   → May be OpenAI service issue

   PATTERN 4: No Errors but Stuck
   → No rate limit/error messages
   → WebSocket disconnected
   → Worker may still be processing
   → Wait 5-10 more minutes

# Setup New Feature

## Overview
Systematically set up a new feature from initial planning through to implementation structure.

## Steps
1. Create backup branch from dev

2. STOP IF NOT IN PLANNING MODE

2. Ask user to define 
3. **Plan architecture**
   - Plan technical approach
   - Design data models and APIs
   - Plan UI components and flow
   - Consider testing strategy

## Feature Setup Checklist
- [ ] Requirements documented
- [ ] User stories written
- [ ] Technical approach planned

Prompt user to change to agent mode to build
